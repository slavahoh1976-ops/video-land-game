## Скачать

| Компьютер | Файл |
|---|---|
| **Mac с Intel** (macOS 10.14.6 Mojave и новее) | `Ekran-Mac-Intel-<версия>.zip` |
| **Mac на M1/M2/M3** | `Ekran-Mac-AppleSilicon-<версия>.zip` |
| **Windows 10/11** — установка | `Ekran-Windows-Setup-<версия>.exe` |
| **Windows** — без установки (переносная) | `Ekran-Windows-Portable-<версия>.exe` |
| Всё сразу + веб-версия + исходники | `Ekran-All-<версия>.zip` |

**Mac:** распакуйте zip, перетащите «Ekran» (в программе — «Экран») в «Программы». Первый запуск: правый клик по приложению → «Открыть» → «Открыть» (приложение не подписано в Apple — так нужно только один раз).

**Windows:** если появится синее окно SmartScreen — «Подробнее» → «Выполнить в любом случае».

**Обновления** приходят сами: программа проверяет сайт, мигает кнопка с номером версии — «Обновить», и программа сама скачивает новую версию и перезапускается. Проекты и свои кабинеты сохраняются.

**Проекты из «Сигнала»:** «Файл → Открыть» → файл `.sflow.json` — LED-экраны из него откроются в «Экране».

Сайт программы: https://slavahoh1976-ops.github.io/ekran/
