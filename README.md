# Экран — коммутация и питание LED-экранов

**Открыть:** https://slavahoh1976-ops.github.io/ekran/ · **Windows и Mac:** https://slavahoh1976-ops.github.io/ekran/download/

Текущая версия: **1.0.0** (22.11.2026) — список изменений: клик по номеру версии в шапке программы.

Отдельная программа для LED-экранов (раньше — раздел «LED-экран» в программе [«Сигнал»](https://slavahoh1976-ops.github.io/signalflow/)).

## Что умеет
- **Экран из кабинетов** быстро: тип кабинета, сетка столбцы × ряды или размер в метрах; неровные экраны и разные кабинеты.
- **База кабинетов и контроллеров NovaStar** — цифры только из паспортов, у каждой позиции источник; свои кабинеты и контроллеры.
- **Приёмные карты NovaStar** (Armor, 5G COEX, MRV…): выбор карты для кабинета, проверка нагрузки карты и совместимости с контроллером.
- **Прописка портов:** автоматически змейкой или вручную, частота и глубина цвета, защита от перегруза порта, резерв порт-в-порт.
- **Питание:** линии по фазам, автоматы, ток с cos φ, нарезка веток.
- **Лист «Схема коммутации и питания»** (PNG / SVG / печать), **калькуляция** (PDF, печать, CSV).
- **Экспорт в NovaLCT файлом .scr:** Screen Configuration → Screen Connection → Load from File → Send to HW.
  Формат .scr — по открытой библиотеке [novastar.js](https://github.com/sarakusha/novastar) (MIT, © Andrei Sarakeev), сверен байт в байт с файлом, сохранённым в NovaLCT.

## Устройство репозитория
- `index.html` — сайт (GitHub Pages), `desktop/index.html` — та же программа для приложений, `version.json` — номер версии для обновлений.
- `src/` — исходники: `prod_ekran.js` (название, версия, сайт), `led.js` (LED-экраны), `scr.js` (файл .scr), общий код `lib.js`, `art.js`, `app.js` (тот же, что у «Сигнала»). Сборка: `python3 src/build.py`.
- `app/` — оболочка Electron 26 (Windows и macOS 10.14+). При изменении `app/**` GitHub Actions собирает приложения и выкладывает их в Releases с номером версии в именах файлов.

## Данные
Проекты сохраняются в файлы `.ekran.json` (открываются и файлы `.sflow.json` из «Сигнала»). В браузере программа хранит данные отдельно от «Сигнала»; при первом запуске сама переносит LED-экраны и свои кабинеты из «Сигнала» на этом же сайте.
